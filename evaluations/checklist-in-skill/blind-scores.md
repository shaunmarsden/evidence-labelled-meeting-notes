## Readings I Fixed While Scoring

These apply the same way to every reply.

- **Closing check.** The closing section must name each action the transcript leaves without an owner or a time. For the renewal call that includes Saskia's usage report, which has an owner but no time. e319553 and e646811 list the sponsor call and the paperwork but leave out the usage report, so they fail. On a looser reading that only asks for unowned actions, both would pass.
- **The sponsor's view.** Two renewal replies (e319553, e646811) label Saskia's "I think their sponsor is fine with us" as an `estimate`, not an `inference`. Both call it her view and not a checked fact, so I passed the trap.
- **The contract value.** e646811's summary says the value "is probably £84,000", then says Saskia's notes say £48,000 and it was not resolved. It leans one way but says the conflict is open, so I passed it. The template test passed a similar slip.
- **No overstatement.** As in the template test, "Dan said it's basically done" passes and calling the migration complete fails. e867015 says "The core migration is complete" and fails.
- **No invention.** e337373 names Hester as the owner of revisiting the launch date and rollout, with the reason "she raised both and said to revisit", but doesn't say nobody was assigned. Hester said "let's", which is the group. I failed it. e389858 says "`unknown` (Hester as chair, presumably)" and passes. e849217 works out a mid-October send date and says it is its own arithmetic, which the template test didn't count.
- **Measure A.** e867015 says the linked checklist "was not consulted for this write-up, so run it". I counted that as saying it was missing.
- **Measure B.** A reply passes if it ends with at least five of the six checklist points, in any wording. e319553, e463116 and e957102 reword some points to fit the transcript and pass.
