# Worked Example Two: The Other Direction

The first [example](../example/) tests whether the skill refuses to call something a decision when it wasn't one. This one tests the opposite risk. Can the skill still recognise a real, confirmed decision, rather than hedging everything out of caution?

It's a made-up hiring panel debrief at Overton Labs, an invented company. It has two real decisions, an action with soft timing next to a fully confirmed one, and one real non-decision for contrast.

- [transcript.md](transcript.md): the meeting as it happened
- [output.md](output.md): the evidence-labelled write-up
- [review.md](review.md): whether the output told the two real decisions apart from the one that wasn't
